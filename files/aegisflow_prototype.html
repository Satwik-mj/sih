Incident log

Data provenance: this sandbox has no live network access to the Overpass/OSM API, so live OSMnx download wasn't possible here. Instead this prototype ingests a real, unaltered OpenStreetMap XML extract of West Oakland, CA (one of OSMnx's own published test-fixture datasets) and replicates OSMnx's own graph-construction step in Python — parsing <node>/<way> elements, computing haversine segment lengths, and simplifying to an intersections-only topological graph — then exports it to JSON for this browser engine. Every road segment below carries its real OSM name, length, highway class, lane count and directionality; speed limits use the real \'maxspeed\' tag where present and standard traffic-engineering defaults by road class where it is not. Wards/shelters are demo role-assignments on top of real nodes (one shelter, Prescott School, is a real OSM point of interest). Elevation/flood terrain remains a procedural stand-in for true DEM ingestion (CartoDEM/SRTM), which needs the same external network access. The C++ kernel, PostGIS store, live IMD/CWC feeds and Docker packaging from the full proposal aren't reproducible in this sandbox either.
